# Python Dictionaries

This folder contains Python programs demonstrating dictionary concepts from basic to intermediate level.

## 📂 Files Included

- `dictionary_creation.py` – Creating dictionaries using different methods.
- `dictionary_characteristics.py` – Dictionary properties, unique keys, mutable nature, and data types.
- `accessing_values.py` – Accessing values using keys, `[]`, and `get()`.
- `adding_and_updating.py` – Adding new key-value pairs and updating existing ones.
- `removing_items.py` – Removing items using `del`, `pop()`, `popitem()`, and `clear()`.
- `dictionary_methods.py` – Common methods such as `keys()`, `values()`, and `items()`.
- `looping_dictionaries.py` – Iterating through dictionaries using loops.
- `copy_and_setdefault.py` – Copying dictionaries and using the `setdefault()` method.
- `nested_dictionaries.py` – Working with dictionaries inside dictionaries.
- `dictionary_comprehension.py` – Creating dictionaries using dictionary comprehensions.

## 📚 Topics Covered

- Dictionary Creation
- Dictionary Characteristics
- Accessing Values
- Adding & Updating Items
- Removing Items
- Dictionary Methods
- Looping Through Dictionaries
- Copying Dictionaries
- `setdefault()`
- Nested Dictionaries
- Dictionary Comprehension

## 🎯 Learning Objectives

- Understand Python dictionaries and key-value pairs.
- Perform CRUD (Create, Read, Update, Delete) operations.
- Iterate efficiently through dictionaries.
- Work with nested dictionaries.
- Build concise dictionaries using dictionary comprehensions.
