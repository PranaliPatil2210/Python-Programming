# File Handling in Python

This folder contains programs demonstrating Python file handling concepts.

## Topics Covered

- Opening Files
- File Modes (r, w, a, x)
- Reading Files
  - read()
  - readline()
  - readlines()
- Writing Files
  - write()
  - writelines()
- Append vs Write
- File Pointer
  - tell()
  - seek()
- Copying Files
- File Handling programs
- Student Record System (Mini Project)

## Files

| File | Description |
|------|-------------|
| file_modes.py | Opening files and different file modes |
| reading_files.py | Reading files using various methods |
| writing_files.py | Writing and appending data to files |
| file_pointer.py | Using tell() and seek() |
| copy_file.py | Copy contents from one file to another |
| practice_programs.py | Practice programs based on file handling |
| student_record_system.py | Menu-driven mini project using files |

## Concepts Practiced

- Permanent data storage
- Reading and writing text files
- File pointer manipulation
- Working with multiple files
- Building a simple record management system
